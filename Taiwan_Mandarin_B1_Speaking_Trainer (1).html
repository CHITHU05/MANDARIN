Speaking check: open this page through localhost (2 minutes, once)
  1. Install Python if you don't have it: on Windows, get Python 3 free from the Microsoft Store. Macs already have it.
  2. Open the folder that holds this file. Windows: click the folder's address bar, type cmd, press Enter. Mac: right-click the folder → New Terminal at Folder.
  3. Type python -m http.server 8000 (Mac: python3 -m http.server 8000) and press Enter. Keep that window open.
  4. In Chrome, go to http://localhost:8000/Taiwan_Mandarin_B1_Speaking_Trainer.html and click Allow when asked for the microphone.
    Word list: official TOCFL vocabulary list (2023 edition, SC-TOP), Novice to Level 3. Meanings: TBCL, SC-TOP 2011 list and CC-CEDICT (CC BY-SA 4.0). The voice is your device's built-in speech voice. The speaking check uses your browser's speech recognition: it tells you whether a Mandarin listener understood the word and which tone it heard. It can't grade your accent, so also practise with a teacher. Your ticks are saved only in this browser.
